# Kassa — касса и взаиморасчёты

Приложение Qt Widgets для Windows 10/11 x64. Использует все три существующие формы `.ui`, доступные для редактирования в Qt Designer. Поддерживает приход, расход, начальный остаток, журнал, очистку журнала с подтверждением и распределение суммы между тремя участниками.

## Скачать для Windows

В GitHub откройте **Actions → Windows portable build → успешный запуск → Artifacts → Kassa-windows-x64**. Распакуйте архив артефакта, затем вложенный `Kassa-windows-x64.zip`. Запускайте `Kassa/Kassa.exe`, сохраняя рядом DLL и папку `platforms`. Устанавливать Qt или Qt Creator не требуется. Артефакты доступны после успешной сборки и хранятся 30 дней; скачивание может потребовать входа в GitHub.

## Работа

- Введите начальный остаток. Итог обновляется сразу: остаток + приход − расход.
- «Приход» / «Расход»: положительная сумма с точкой или запятой, максимум 999999999,99. Выберите одного участника 1–3; без выбора операция относится к общей кассе (0). Enter добавляет операцию, оставляя окно открытым; OK добавляет и закрывает; Cancel закрывает без добавления текущего ввода. Уже добавленные через Enter операции сохраняются.
- «Взаиморасчёты»: показывает чистые поступления по участникам и общей кассе. Введите общую сумму, которую должны получить участники 1–3 поровну. Программа вычитает долю из чистых поступлений каждого участника и показывает переводы. Положительный баланс означает передать, отрицательный — получить. Невязка проходит через общую кассу (0). Копейки от деления на 3 распределяются последовательно участникам 1 и 2. Начальный остаток относится к кассе 0 и не меняет индивидуальные балансы участников.
- Очистка удаляет операции, сохраняя начальный остаток.

**Учёт ведётся в памяти текущего сеанса. Закрытие приложения удаляет журнал** — как в исходной программе. Автоматического сохранения, экспорта и интеграции с фискальным оборудованием нет.

## Сборка и проверки

C++17, CMake ≥ 3.21, Qt Widgets и Qt Test (Qt 5.15 или Qt 6). Windows CI использует MSVC 2022 x64 и Qt 6.8.3.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
cmake --build build --parallel 2
ctest --test-dir build --output-on-failure
```

Тесты проверяют денежный ввод, сохранение копеек, взаиморасчёты, OK/Enter/Cancel, исключительный выбор участника, журнал, начальный остаток и повторное заполнение расчёта. `Kassa --smoke-test` создаёт главное окно и завершает цикл событий через 500 мс; это проверка запуска, а не полный пользовательский тест.

Для ручной Windows-сборки используйте x64 MSVC developer shell с Qt в PATH, генератор `-G Ninja`, затем PowerShell:

```powershell
./scripts/package-windows.ps1 -BuildDir build -OutputDir dist
```

Скрипт вызывает `windeployqt`, добавляет app-local MSVC CRT и создаёт ZIP. CI дополнительно распаковывает ZIP и запускает его без Qt в PATH, затем публикует только прошедший проверку архив. Workflow срабатывает на push, pull request и вручную. Сохраняется также исходный проект `kassa/kassa.pro` для Qt Creator/qmake.

## Анализ исходного проекта

Исходный проект состоял из 11 файлов в `kassa`, без CI и тестов. Реализованы журнал прихода/расхода, сумма с начальным остатком, последовательный ввод через Enter, очистка и окно взаиморасчётов. Исправлены несовпадения классов `Form`/`InputDialog`/`Delegate` в UI, отсутствие записи через OK, повторное открытие диалогов, неоднозначный выбор нескольких участников, отсутствие проверки сумм, редактирование таблицы без пересчёта, устаревающее глобальное состояние и некорректные ветви расчёта переводов. Денежные значения хранятся в целых копейках. Все окна используют layout, русские подписи и масштабируются.
